# 🐶 Cachorrinho Mágico: Classificação Mágica (Wizard Puppy: Magic Sort)

Clone aprimorado e modernizado do jogo original do **YouTube Playables**, reconstruído com **React 18, TypeScript, Tailwind CSS, Vite e WebAudio API**.

## ✨ Características e Aperfeiçoamentos
- **195 Níveis Originais Decodificados**: Níveis com mecânicas fiéis reconstruídas a partir das tabelas binárias do jogo original.
- **Mecânicas Especiais & Obstáculos**:
  - 👑 **Garrafa Gigante (Capacidade 13)**
  - 🎭 **Cortinas Mágicas (Simples e Numeradas)**
  - 🪨 **Pedestais de Argila**
  - 🛡️ **Gesso Secreto (quebra com garrafas adjacentes)**
  - ❓ **Líquido Oculto Misterioso**
- **Oráculo IA (Dica Inteligente Gratuita)**: Analisador heurístico que indica o melhor movimento disponível.
- **Acessibilidade Completa**: Modo daltônico com símbolos alquímicos sobre poções e pedidos.
- **Multi-idioma**: Suporte a Português (PT-BR) e Inglês (EN-US).
- **Zero Anúncios / Sem Espera de Energia**: Experiência fluida e instantânea.
- **Sintetizador Sonoro Procedural**: Efeitos sonoros cristalinos com WebAudio API (zero dependência de assets de áudio externos).

## 🚀 Como Executar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Fazer build de produção
npm run build
```
